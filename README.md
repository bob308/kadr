# Кадр

Android-додаток для особистого користування: телесуфлер поверх камери і автоматичні субтитри для відео.

## Що вміє

**Телесуфлер**
- текст прокручується поверх камери, жовта позначка показує рядок, який читати зараз;
- швидкість і розмір шрифту регулюються повзунками, дзеркальний режим, фронтальна/основна камера;
- відлік 3 секунди перед записом, відео зберігається в галерею (Movies/Kadr);
- після запису кнопка «Додати субтитри» одразу відкриває відео в розділі субтитрів.

**Субтитри**
- розпізнавання мови без інтернету (українська, англійська, російська); модель завантажується один раз;
- субтитри по кілька слів, з підсвіткою слова, яке звучить зараз;
- стиль: контур, плашка або тінь; розташування, розмір, колір, великі літери;
- кожен субтитр можна виправити або видалити;
- збереження відео з вшитими субтитрами в галерею та експорт файлу .srt.

## Як отримати APK

Збирається автоматично на GitHub при кожному оновленні коду (вкладка Actions).
Готовий файл з'являється в розділі Releases. Постійне посилання на останню версію:

`https://github.com/<ваш-логін>/<назва-репозиторію>/releases/latest/download/Kadr.apk`

На телефоні: відкрити посилання → завантажити → відкрити файл → дозволити встановлення з цього джерела → «Встановити».

## Збирання на комп'ютері

Android Studio → Open → ця папка → Build → Build APK(s).
